## 🌟 Overview

High-performance, production-grade portfolio application engineered with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS**, and **Fastify**. It showcases:

- **28 Full Design Systems & Themes**: From Claymorphism, Neumorphism, Neobrutalism, and Swiss Style to Cyberpunk 2077, 8-Bit Retro Pixel, Terminal Matrix, and Vaporwave.
- **Dedicated Hero Architectures**: Each theme features its own custom hero layout, kinetic animations, and strictly aligned dual-column frames.
- **Ali AI Assistant**: Embedded intelligent assistant trained on commercial client case studies, live theme manipulation, and interactive dialogue.
- **Comprehensive Commercial Client Showcase**: Ivana Studio, Nexcurex, Arshad Tiles, VetCarePlus, and Shah-Sweet.
- **100/100 Lighthouse SEO Suite**: Complete JSON-LD Structured Data (`Person`, `WebSite`, `ProfessionalService`), dynamic OpenGraph/Twitter cards, and canonical search indices.

## 🚀 Tech Stack

- **Framework**: Next.js 15 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS, CSS Custom Properties Design Token Engine
- **Icons**: Lucide React
- **State Management**: Zustand
- **Animations**: Motion (Framer Motion v12), HTML5 Canvas Particle Engine, GPU CSS3 Keyframes
- **Backend / API**: Node.js & Fastify with CORS and Socket connectivity
- **SEO & Compliance**: Schema.org JSON-LD, Sitemap XML, Robots.txt, OpenGraph, Web App Favicon Engine

## 🛠️ Local Development

### Prerequisites
- Node.js >= 20.x
- pnpm >= 9.x

### Installation
```bash
# Clone the repository
git clone https://github.com/alikhan14756/Portfolio.git

# Install all dependencies
pnpm install

# Start development servers
pnpm dev         # Starts Next.js client on http://localhost:3000
pnpm dev:server  # Starts Fastify backend on http://localhost:4000
```

### Production Build
```bash
pnpm build
```
